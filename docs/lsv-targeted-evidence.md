and a comparison of independently validated observations. It provides no import,

## Explicit private query, never discovery by rank

The caller must pin one exact `LevelCache/<name>.lsf` archive path and the reviewed
exact selectors. No member is selected by size, archive position, largest/first
match, fuzzy name or inferred location. Other manifest entries are validated by
the approved parser but their payloads are not read. Missing/wrong members fail
closed. The adapter currently accepts flat LevelCache names only; it does not
broaden archive/path support.

A previously authorized manifest-only listing of ground save B enumerated
candidate LevelCache names for caller disambiguation. No member payload was
decoded, no member was selected, and inventory save A was not read. The source
was verified unchanged. The private listing is not stored in the repository.
The caller subsequently confirmed one exact member for B ground-side inspection.
No location inference, size ranking or automatic selection was used.

The exact Stats token is available from the prior validated diagnostic, whose
sanitized result confirms its equality across the previously observed family.
Stats selects a family, never a unique item instance. Private query values and
member names are passed in memory and never included in the evidence report.
No fresh Globals collector is added or automatically run.

## APIs and measurement lifecycle

- `scripts/measure-lsv-targeted-evidence.cjs`: `measure(source, plan, options)`
  reads only the caller-selected file, opens it read-only with leaf-symlink
  rejection, enforces the existing 128 MiB file bound, reads bounded chunks,
  and records fingerprint/stat identity privately in memory. It uses the
  committed targeted controller and a disposable real Worker running the
  committed browser research Worker in a restricted VM. The VM cannot access
  filesystem, process, network, storage, console or unrelated modules.
- Source bytes are never written, extracted to files, repacked or copied into
  git. Verification rereads the original descriptor and checks the named path
  against the original device/inode/stat identity and digest. Content changes,
  deletion or replacement suppress observations. Readability/stability failure
  is reported as `not verified`; successful verification as `unchanged`.
- One absolute monotonic deadline includes source preparation, Worker startup,
  inspection, projection and final source verification. The Worker receives
  only remaining time. Projection continues the inspector's consumed work
  accounting (including bounded schema-key/string/JSON processing) under the unchanged 24M ceiling; it does not acquire a fresh scan
  budget. The 30-second maximum and all parser/codecs/structural bounds remain
  unchanged. Verification still runs after a failed attempt to check source
  stability; this does not authorize more decoding after the deadline.
- Cancellation terminates the active Worker. Failure returns fixed diagnostics
  and operational timing only, never partial observations. A fresh independent
  attempt is required for recovery. No failure path silently retries.
- `gather({groundB, inventoryA?, plan, allowA?, assessB?})` always starts B.
  Supplying A is not sufficient to read it. Failed/unverified/zero-target B
  prevents A. A positive target still requires an explicit B-dependent
  assessment selecting a narrowly defined supported-schema comparison question.
  A may then run as a NEW bounded attempt. A failure suppresses comparison while
  retaining the independently verified B result.

CLI (B only): `node scripts/measure-lsv-targeted-evidence.cjs GROUND_B`.
Supply a bounded JSON `{memberName, selectors}` plan on stdin. No private paths
or selectors are embedded in committed configuration. There is no report-file
option. Additional CLI source arguments reject; optional A is a deliberate module
workflow after B assessment, not automatic command-line enumeration.

## Projection and comparison limits

`experiments/lsv/targeted-evidence.cjs` accepts only validated inspector reports.
It projects allowlisted/redacted ancestor labels, selected attribute name/type/
length/opaque descriptors, selector handles, matched-field descriptors and multiplicities. Equality moving
between supported fields remains a difference even when the other row descriptors
are identical. It never reads
scalar values or opaque contents and excludes node/attribute indices and value
offsets from cross-save shape keys. Supported attributes named Position/Transform
establish descriptor presence only, not the meaning or coordinates of placement.

Bounds remain 1,024 selected records, 4,096 contexts, 8,192 equality observations,
64-level paths and 512 KiB sanitized output. Attribute-descriptor reservations
also enforce the existing 4 MiB evidence envelope. Comparisons are separately
bounded to 100,000 charged operations, a 30-second maximum and 512 KiB output.
They compare aggregate schema-shape multisets, never Cartesian record pairs.
Private exact query contracts are retained only in a WeakMap; different queries
or serialized/reloaded reports cannot silently compare by coincidentally equal
`selector-1` labels. Contracts are caller-pinned, not authentication of hostile
callers. No raw selector value/hash or private source fingerprint is emitted.

Comparison labels explicitly mean `INVENTORY_SAVE_A` and `GROUND_SAVE_B`.
Attempts are **SEPARATE_NOT_ATOMIC**. Shared schema shape counts do not prove
unchanged state, matching scalar values, exact UUID continuity, ownership or a
handoff. Repeated candidates retain multiplicity; no first-match resolution is
used. Redaction can merge schemas. Stats/CurrentTemplate families and nearby
context are insufficient instance keys. Opaque NewAge/ECS remains uninspected.
